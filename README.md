# AI 技术雷达

每天自动生成的一份 AI 技术进展日报，聚焦 Agent 架构与自进化、训练/推理方法、推理成本与评测。

## 内容口径

收录标准只有三条，满足其一才进：改变能力边界、改变单位成本、改变做法。行业信息（融资、电力、诉讼、平台准入）不单独成章，只作为开篇「环境｜约束条件」出现，用来说明技术选择的约束。

明确不收：纯榜单刷分、纯增量调参、应用层产品发布、与技术的无关融资。

## 结构

- `YYYY-MM-DD.md` — 每日日报
- 每份包含：今日一句话 / 环境与约束 / Agent 架构与工程 / 论文与方法 / 模型与开源 / 推理成本与基础设施 / 评测与基准 / 今日判断 / 覆盖与不确定

- 由 WorkBuddy 定时任务自动生成并推送，每天北京时间 09:00。
