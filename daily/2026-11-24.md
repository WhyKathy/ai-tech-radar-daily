## 1. Agent 架构与工程

- **[P0] Anthropic 发布 Claude Ship：代码审查智能体套件加入按策略自动批准，团队设定的策略文件决定哪些 PR 不再需要人签字** — TechCrunch 11-23 报道。Claude Ship 由三部分组成：Code Review（已正式开放）、PR Steward（Beta，处理 CI 检查失败、合并冲突与审查反馈并记录变更，不自行批准或合并）与 Claude Approvals（Beta，按团队设定的策略自动批准常规改动，安全、支付、权限等敏感区域仍要求人工签字）。目前支持 GitHub 仓库，面向 Claude Team 与 Enterprise 用户；官方建议先以观察模式运行，可设月度支出上限并保留人工升级决策权。→ 价值：AI 生成的代码从"审查辅助"进入"自动批准"，批准规则从厂商承诺变成仓库里可审计的策略文件；对 agent 产出的准入层设计而言，这是一份可直接套用的治理形态——策略外置、敏感区例外清单、观察模式先行、支出上限兜底。｜来源：[IT之家转述 TechCrunch](https://baijiahao.baidu.com/s?id=1882694867275677641&wfr=spider&for=pc)、[ReadHub](https://readhub.cn/topic/8yIoAw6DlDe)｜2026-11-23

- **[P0] ZhuLong-SE：EDA 脚本自进化 agent 的三层经验记忆库，入库配真值锚定、反证过滤、留出集回滚与防泄漏检索四道闸门** — arXiv 11-19 提交（周一公告批次 11-23 上线）。agent 从历史执行轨迹蒸馏可复用知识进三层记忆库，入库受四道闸门约束：真值锚定（ground-truth anchoring）、反证过滤（disconfirmation filtering）、留出集回滚（held-out rollback）与防泄漏检索（anti-leakage retrieval）；harness 侧加 API 检索、文档响应、隔离沙箱执行与静态检查。158 题基准上关闭自进化达 92.4% pass@1，五个受测 LLM backbone 全部超过基线 ZhuLong；更难的 instance-disjoint 测试集上，从裸配置出发的自进化超过人工编写经验基线 2.5 个百分点（80.0% vs 77.5% pass@1）。→ 价值：自进化系统的经验入库拿到了一份完整的治理清单——什么能进记忆、什么被反证剔除、什么触发回滚、检索时如何防泄漏，全部给出可复用的机制名称与对照数字，可直接搬到任何带外部验证器的经验蒸馏流程上。｜来源：[arXiv:2611.26912](https://arxiv.org/abs/2611.26912)｜2026-11-19

- **[P1] Google DeepMind 与 Quantum AI：多组 Gemini 4 智能体优化量子算法，每个结果经 Lean 形式化验证后才放行，Lean 库开源** — 11-23 发布。资源密集型量子电路无法在经典计算机或现有小规模量子处理器上实测，团队用形式化定理证明器 Lean 对每项优化做数学验证：惯性约束聚变关键属性计算的综合算力成本降低 11.8 倍（纠错量子比特 5,650→4,338），光敏分子量子模拟成本降低 8 倍，细胞色素 P450 模拟内存占用 481→333 量子比特、性能提升 2.5 倍，Grover 特定实现提速 2.57 倍，反正弦子程序最高提速 290 倍；Lean 库、问题定义与已验证方案已在 GitHub 开源。谷歌同时说明优化后仍超出第一代纠错量子计算机的可用算力，数字对应不同任务与指标。→ 价值：当 agent 产出无法用运行反馈验证时，形式化证明充当准入闸门——「生成 + 形式化验证 + 人工定问题规范」的分工对任何存在验证器缺口的自进化流程都可直接借用。｜来源：[IT之家](https://www.ithome.com/1/031/232.htm)、[AIBase](https://news.aibase.com/zh/news/32481)｜2026-11-23

## 2. 论文与方法

- **Bel: Step-Level Policy Improvement of Visual Agents Without Training** ｜未标注机构（Jiajun Fan、Ge Liu 等）｜[arXiv:2611.27222](https://arxiv.org/abs/2611.27222) ｜2026-11-20
  方法：不训练任何参数，只把候选动作画在它所作用的截图上再交给决策模型打概率——同一个"点击"以文本坐标呈现时是两个数字，画在屏幕上则是空草稿旁的发送按钮，判断显著变准；贪心解码得分低于阈值且落后候选一个 margin 时才切换动作。
  价值：三个策略在移动、网页、桌面步级测试上全部显著超过贪心解码，也显著超过投票、CATTS、训练过的 GUI-Critic-R1 与两个同提示的 Qwen3-VL 判官，并显著提升 Qwen3-VL-235B-A22B；阈值不变即可迁移到 AndroidWorld、MiniWoB++ 实机任务与两组机器人指点基准。「在动作发生处判断动作」是推理时步级改进的一类轻量做法，零训练成本。

- **Speculative Decoding Is Less Speculative Than You Think（DICE）** ｜Guanning Zeng、Andrea Zanette｜[arXiv:2611.27891](https://arxiv.org/abs/2611.27891) ｜2026-11-20
  方法：把采样随机性与模型预测两类不确定性分开——采样随机数可以在 drafting 前固定并同步到验证侧，DICE 据此把 drafting 算力集中到「本次采样更可能真正被采用」的续写上，贯穿 draft 树的节点选择并扩展到异步预取下一轮草稿。
  价值：不加 drafter 训练、不改目标模型采样分布，在多种设置下取得 SOTA 解码吞吐，相对强基线加速最高 24.6 个百分点；投机解码的提升空间有相当一部分被定位在「随机性对齐」而非更好的 drafter，serving 侧可直接在现有 draft 管线上实现。

## 4. 推理成本与基础设施

- **[P1] MemOnce（南京大学等）：可学习记忆状态架构，Qwen3.5-4B 适配后 1M 上下文下记忆缓存减少 1313×、prefill 延迟降 6.9×、吞吐提升 3.5×** — arXiv 11-20 提交（周一公告批次）。两个核心设计：记忆编码器-解码器只缓存最终层隐状态的小子集作为紧凑记忆表示，注意力层用时动态解码回 KV cache；记忆稀疏注意力对每个持续输入自适应检索相关记忆，稀疏索引跨层只计算一次。整体记忆性能 +5.77%，可零样本泛化到下游表示任务；在多尺寸、多上下文长度与预训练/后训练适配两类范式下均超过 Transformer 及其他架构。→ 价值：长上下文与持续交互场景的 KV cache 线性增长多了一条架构级路线，1M token 量级的显存与 prefill 成本被压约三个数量级；代价是需要做后训练适配，不是即插即用替换。｜来源：[arXiv:2611.27973](https://arxiv.org/abs/2611.27973)｜2026-11-20

## 今日判断

**① 技术上最值得跟进的 3 条**

1. **ZhuLong-SE 的经验入库闸门（11-19）**：真值锚定、反证过滤、留出集回滚、防泄漏检索四道闸门 + instance-disjoint 测试下自进化仍胜人写经验 2.5pp——这是自演化系统「经验记忆怎么管」目前最完整的一份公开配方，且每一道闸门都对应可实现的检查逻辑。
2. **Claude Approvals 的策略文件自动批准（11-23）**：代码合并的批准权第一次以可审计的策略文件形式交给 agent，配套观察模式与支出上限。agent 产出从「人来审」走向「策略来审」，这一步的治理形态对所有 agent 产出入库/上线的场景通用。
3. **DeepMind 的 Lean 验证闸门（11-23）**：在产出物无法运行验证的场景里，形式化证明充当外部验证器，多智能体搜索照常运转。这与 ZhuLong-SE 拼成同一课：自进化的准入层可以缺运行反馈，但不能缺一个独立于生成器的验证信号。

**② 对 harness 设计、模型选型、推理成本、研究方向的影响（判断）**

- **Harness 设计**：经验记忆的写入路径按「锚定 → 反证 → 留出集回滚 → 防泄漏检索」四步建闸门，入库标准与能力评估分离；agent 产出的自动批准从策略文件起步，敏感操作保留人工例外清单，先观察模式后放开；无运行反馈的任务考虑引入形式化验证或等价的独立证明信号，而不是让生成器自评。
- **模型选型**：Chat 与 Work/Codex 分线意味着对话模型换代不再等于 agent 底座换代，选型表应对两条线分别记录版本与退役日期；GPT-6.2 的可操控性下降（60.6%→48.6%）提示任何接进流程的对话模型升级都要重跑可操控性用例；Bel 表明小策略模型 + 判断模型的组合无需训练即可提升步级成功率，指导资产的复用面从工具调用扩展到视觉动作。
- **推理成本**：长上下文成本曲线存在架构级下修空间（MemOnce 的 1313× 缓存压缩、6.9× prefill），但属「重新适配」类收益，评估时应与「即插即用」类（DICE 的随机性对齐，无需训练）分开核算；投机解码侧优先尝试零训练的随机性对齐改造。
- **研究方向**：准入层三例（经验闸门、策略批准、形式化证明）指向同一问题——自演化系统的下一步基础设施是更便宜、更独立于生成器的验证；验证信号的形式（运行反馈、策略匹配、数学证明）可以不同，独立性要求一致。

**③ 明后两天要看的 2 个信号**

- **策略自动批准的真实反馈**：看什么——Anthropic 文档更新、Claude Approvals 观察模式的用户事故报告或第三方复测；什么算确认——出现首个公开的误批准/漏批准案例分析，或官方给出解除 Beta 的时间表与默认策略模板。
- **经验记忆治理的扩散**：看什么——后续 arXiv 批次与 HF Daily Papers 是否出现第二篇带「锚定/回滚/防泄漏」闸门消融的经验蒸馏工作；什么算确认——新工作引用同类闸门设置或给出与 ZhuLong-SE 的对照消融。
