## 1. Agent 架构与工程

- **[P0] ComputeWise（Salesforce AI Research）：AI 研究智能体的 GPU 时间只有 52% 花在答案需要的工作上，一套「提示词 + 确定性代码」的 harness 移除了八成以上浪费** — arXiv 11-23 提交（周二公告批次 11-24 上线）。开源基准内置一个模拟 GPU，向 agent 回放真实录制的运行记录，无需真实 GPU 即可跑数百次实验；五个模型在无帮助下把 52% GPU 时间用于答案所需工作、22% 用于不必要工作、26% 空转；要求更快完成、保持 GPU 忙碌或提供作业调度器都不能修复；开源 harness（部分提示词、部分确定性代码）在五个模型上移除超过 80% 的多余时间。代码与数据已开源（SalesforceAIResearch/computewise）。→ 价值：agent 任务的成本主体在 GPU 侧而非 token 侧，且浪费可以被测量再被确定性代码消除——「先测量、再以 harness 而非提示词修复」的结构可直接搬到任何带执行环境的 agent 流程。｜来源：[arXiv:2611.31027](https://arxiv.org/abs/2611.31027)｜2026-11-23
- **[P1] CUA-SEE：让评测环境与 computer-use agent 对偶演化的闭环框架，任务、探针、验证器三线共进化** — arXiv 11-23 提交（周二公告批次）。从 rollout 证据共同演化任务与可执行验证器，三条目标解耦：基准演化按队列校准难度与覆盖度扩范围，诊断演化用 agent 条件化的能力边界探针提高分辨率，验证器演化把持续变化的需求翻译成状态锚定的检查点并做对抗校验；跨多智能体、多应用、多轮生成有挑战且可测量的任务，同时保留过程级证据。→ 价值：自进化 agent 的评测端第一次给出与生成端对称的演化配方——任务难度、诊断粒度、验证精度三者分开演化，防止静态基准的天花板效应稀释判别力。｜来源：[arXiv:2611.30962](https://arxiv.org/abs/2611.30962)｜2026-11-23
- **[P2] Embo-Harness（NTU MMLab）：前沿多模态模型直接当机器人策略的系统化 harness 研究，蒸馏出六条经验配方** — arXiv 11-23 提交（周二公告批次）。拆解机器人 agent 回路的四个组件（提示、规划、动作执行、工具使用），配方优先利用模型原生视觉推理与工具调用接口，而非手工规划、技能库或动作先验；给出动作表示、分块、推理力度、视觉观测、短多动作序列与策略精化的有效选择。RoboLab-120 上 83.3% 成功率，超最强已报基线 26.2 个百分点；20 次四类真实操作任务零样本尝试成功 15 次。控制变量实验显示模型对准确空间目标估计的依赖强于对底层关节/轨迹生成的依赖。→ 价值：「强基座 + 薄 harness、接口优先于先验」的结论在机器人域再次得到量化支持，配方条目可迁移到其他以感知为主的 agent 域。｜来源：[arXiv:2611.31201](https://arxiv.org/abs/2611.31201)｜2026-11-23

## 2. 论文与方法

- **Unlocking the Power of Loops in Pretrained LLMs with Loop Residuals（LoopRes）** ｜新加坡国立大学（杨易团队等）｜[arXiv:2611.31094](https://arxiv.org/abs/2611.31094) ｜2026-11-23
  方法：在 Attention Residuals 基础上让每个循环层直接注意此前各轮循环的输出，为每轮输出配可训练的 loop-aware key 编码结构身份，并把每层注意力限制在最近 W 轮的残差窗口内，迫使逐轮增量构建；无需从零预训练，对已训好的 LLM 微调改造成循环架构。
  价值：3 个模型家族、6 个预训练 LLM、9 个基准上一致有效——2 倍计算下 Qwen3-1.7B-Base 较 SFT 提升 29.1%（超过 SOTA 基线增益的两倍），最大验证到 30B，且从 1.7B 到 8B 随计算增长的爬升陡于 SFT；与 GLM-5.4 同日出现，构成「循环路线」的旗舰落地 + 开源可复现方法两个信号。
- **MiniMax 称其模型攻破多个 NIST 密码竞赛候选算法，公开挑战赛较最优已有算法加速数百至数万倍（待核实）** ｜MiniMax（厂商自报）｜[每日 AI 大事件简报转央广网/证券时报](http://mp.weixin.qq.com/s?__biz=MzY5NTQ1OTczOQ==&mid=2247483768&idx=1&sn=b34e07e02b512a84d65e0179648be1a0&chksm=f5b03be5bfea76881a9f95f9455fd024bf30904c87c8c28926fa6e4127489092d58a1a748b0e#rd) ｜2026-11-22
  方法：厂商公告口径，称把此前无已知实际攻击的历届 NIST 候选算法的理论攻击推进到秒级—分钟级；未见论文、代码或第三方复现。待核实。
  价值：若独立复现成立，AI4S 的能力边界从数学证明扩展到密码攻防，且攻防两用属性会直接进入安全评估与红队讨论范围。

## 4. 推理成本与基础设施

- **[P1] LiveLoRA：LoRA 适配器更新时的精确 KV Cache 迁移，32 会话 × 8K 场景对全量重 prefill 的中位发布加速 68.98×，解码开销约 4.8%** — arXiv 11-23 提交（NeurIPS 2026 Workshop AgenticOS 接收）。冻结低层解码块并固定 K/V 适配器下投影，使每个 token 的基座投影与低秩坐标跨适配器版本保持不变；运行时重建候选 K/V、经最终块重估最新 token 后原子提交适配器、缓存与下一 token logits，并证明在所述模型假设下与全历史重 prefill 精确等价；Qwen2.5-3B-Instruct 上五次运行中位配对发布加速均值 68.98×，相对原生缓存解码开销约 4.8%，紧凑保留较边界回放再省 3.42× 会话存储（8K）。→ 价值：持久化 agent 换 adapter 版本不再需要重放全部交互历史——多 adapter 热切换的 serving 成本从「会话数 × 历史长度」降为常数级，等价性有形式化证明而非经验近似。｜来源：[arXiv:2611.31105](https://arxiv.org/abs/2611.31105)｜2026-11-23

## 今日判断

**① 技术上最值得跟进的 3 条**

1. **循环架构的双信号（11-23）**：GLM-5.4 把 Loop Transformer 推到 750B 旗舰并给出完整的显存工程方案（门控写入、混合 KV、索引复用），LoopRes 同日给出不换基座、微调即可把预训练模型改造成循环的通用方法且增益远超以往。一个证明规模落地可行性，一个提供可复现路径，两者互为印证。
2. **ComputeWise 的 GPU 浪费测量（11-23）**：agent 研究任务的成本主体在 GPU 侧，52% 有效利用率与「提示词修不好、确定性 harness 修得好」的对照结论，把 agent 成本优化从 token 经济学拉回到执行资源经济学，测量工具与 harness 均已开源。
3. **困惑度红线提案（11-22）**：OpenAI 首次公开自家对数困惑度曲线并提议跨厂商共同上限，微软同日按同一标尺披露自家数字——这是能力治理第一次出现可比较的连续量纲，跨厂商是否跟进定义了这个提案是标准还是姿态。

**② 对 harness 设计、模型选型、推理成本、研究方向的影响（判断）**

- **Harness 设计**：执行型 agent 的成本审计应从 token 计数扩展到 GPU 时间构成（有效/无效/空转三分类），先接测量回放再上确定性修复；评测端参考 CUA-SEE 把任务难度、诊断探针、验证精度三条演化线分开维护，避免静态基准随 agent 进化失效。
- **模型选型**：循环架构进入选型表但暂不可采购——GLM-5.4 仅 Coding Plan 可用、API 与权重未开放、无旗舰公开分数，决策窗口在 API 开放后的第三方复测；同架构 30B 对照的「推理链长任务收益最大、输出缩短 10–14%」提示循环模型适合长程任务而非低延迟场景。
- **推理成本**：持久化多 adapter 服务的 KV 迁移（LiveLoRA，68.98× / 4.8% 开销）与记忆原生架构（MemOnce、MemT-1.0-Pro）代表两条不同的长上下文降本路线——前者即插即用、有等价性证明，后者需重新适配；评估时按改造代价分开核算。
- **研究方向**：自进化系统的验证信号清单本周新增两类——执行资源的浪费测量（ComputeWise）与评测环境的对偶演化（CUA-SEE）；生成端演化与测量端、验证端演化需要同步设计，单端进化的系统会先撞上自己评测的天花板。

**③ 明后两天要看的 2 个信号**

- **GLM-5.4 的 API 与第三方成绩**：看什么——API 是否按承诺开放、LMArena/Artificial Analysis 及编程类榜单是否出现独立复测分数、权重开源的许可条款；什么算确认——任一第三方 harness 公布 750B 旗舰实测分数，或权重以明确许可上线。
- **困惑度提案的跨厂商响应**：看什么——Anthropic、Google DeepMind、xAI 是否公布自家对数困惑度数字或表态加入共同上限；什么算确认——第二家厂商按可比数据集披露同量纲数字，或发布明确拒绝参与的声明。
